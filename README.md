# Project Management OS

项目管理与推进方向的公开收藏仓库。

这个仓库用于整理项目拆解、周报、交付物、决策记录、复盘机制和个人执行系统。目标是把模糊想法变成持续推进的项目。

## What Goes Here

- 项目拆解和路线图
- 周报和月度复盘
- 决策记录
- 交付物清单
- 值得收藏或 fork 的项目管理 GitHub 项目

## Structure

- `repos.md`: 项目管理相关 GitHub 仓库索引
- `playbooks/`: 项目启动、推进、复盘流程
- `templates/`: 项目卡、周报、决策记录模板
- `archive/`: 历史项目和旧流程
